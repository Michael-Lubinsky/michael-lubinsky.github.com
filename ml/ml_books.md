Book 1: Understanding Machine Learning
A theoretical introduction to the main concepts and algorithms in machine learning. It is a useful starting point for readers who are new to the field.
https://cs.huji.ac.il/.../understanding-machine-learning...

Book 2: Mathematical Foundations of Machine Learning
Covers the mathematical foundations required for machine learning, including linear algebra, calculus, probability, and optimization.
<https://mml-book.github.io/book/mml-book.pdf>

Book 3: Mathematical Analysis of Machine Learning Algorithms
Examines the mathematical principles and theoretical reasoning behind machine learning algorithms.
<https://tongzhang-ml.org/lt-book/lt-book.pdf>

Book 4: Theoretical Principles of Deep Learning
Explores the theoretical foundations of deep learning and the principles behind modern neural network models.
<https://arxiv.org/pdf/2106.10165>

Book 5: Neural Networks and Learning Machines
Provides a systematic introduction to neural networks and related machine learning methods.
<https://arxiv.org/pdf/1901.05639>

Book 6: Graph Deep Learning
Introduces deep learning for graph-structured data and the fundamental concepts behind graph neural networks.
<https://yaoma24.github.io/dlg_book/dlg_book.pdf>

Book 7: Machine Learning: A Probabilistic Perspective

Presents machine learning through a probabilistic framework and connects theoretical concepts with practical algorithms.
<https://people.csail.mit.edu/moitra/docs/bookexv2.pdf>

Book 8: Probability Theory: Theory and Examples
Offers a rigorous foundation in probability theory, supported by detailed explanations and examples.
<https://sites.math.duke.edu/~rtd/PTE/PTE5_011119.pdf>

Book 9: Fundamentals of Applied Probability
Focuses on practical applications of probability theory across a range of problems.
<https://sites.math.duke.edu/~rtd/EP4A/EP4A_April2021.pdf>

Book 10: Advanced Data Analysis
Covers advanced analytical methods for readers who want to deepen their understanding of statistics and data science.
<https://stat.cmu.edu/~cshalizi/ADAfaEPoV/ADAfaEPoV.pdf>
